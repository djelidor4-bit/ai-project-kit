## מודול web

**סוכן נוסף בטבלת הניתוב** (ממליץ בלבד, כמו כל סוכן מקצועי):

| סוכן | מתי מאצילים אליו | חבילת סקילים (🎯 · 🧠 · 🛡️) |
| :--- | :--- | :--- |
| `web-builder` | איכות האתר כמוצר גמור — קומפוזיציה, ריתמוס, ביצועים, נגישות, מיגור "AI סלופ"; שיפוץ סקשן או ביקורת לפני השקה | SlopDiagnostician · ReductionFirstSpecifier · LaunchBarMeasurer |

**סקילי עיצוב** (מקור ורישיון: `docs/skills-index.md`):
- `taste-frontend` — כיוון אמנותי ואנטי-סלופ, בכל עיצוב סקשן.
- `redesign-premium` — שדרוג מסך קיים.
- `frontend-design` — כיוון אסתטי, טיפוגרפיה ו-motion.
- `design-craft` — hero, תמונה+טקסט, אייקונים, באנרים.
- `design-system` — טוקנים, מפרטי רכיבים ומצבים.
- `ui-ux-pro-max` — נגישות, יעדי מגע, רספונסיביות, מצבי אינטראקציה.

**כללים:**
- שפת העיצוב ב-`docs/design-system.md` נעולה — שינוי = החלטה ביומן. סקיל אינו גובר עליה.
- ממשק מול API: `docs/frontend-api-guidelines.md` (contract-first, mock-first).
- **לפני "אומת" על שינוי ממשק — בדיקה חיה:** 375px מובייל + 1280 דסקטופ · 0 גלישה אופקית · קונסולה נקייה · ניגודיות AA (4.5:1 גוף, 3:1 טקסט גדול) · `prefers-reduced-motion` נכבד. מה שלא נבדק — נכתב.
