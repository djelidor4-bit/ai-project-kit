## הערות ל-Claude Code

החוקה המלאה היא `AGENTS.md`, שמיובא בשורה הראשונה. כאן רק מה שייחודי ל-Claude Code.

- **⚠️ לא מוחקים את שורת הייבוא `@AGENTS.md`.** כשקיים `CLAUDE.md`, Claude Code קורא אותו ולא את `AGENTS.md`; בלי השורה — החוקה לא נטענת.
- **`agent-manager` הוא אתה** — לא מפעילים אותו בכלי Agent. קוראים את `.claude/agents/agent-manager.md` בתחילת סשן ופועלים לפיו.
- **סוכנים:** `.claude/agents/*.md`, מופעלים בכלי Agent בשם הסוכן (למשל `qa`). לעבודת הפרויקט — רק סוכני הפרויקט, לא
  general-purpose או סוכן כללי אחר. הסוכן לא רואה את השיחה: הבריף כולל משימה, קבצים לקרוא, החלטות רלוונטיות ומה להחזיר.
- **סקילים:** `.claude/skills/<name>/SKILL.md`, מופעלים בכלי Skill בשם (למשל `gate-check`).
- **שאלות לבעל הפרויקט:** כלי AskUserQuestion — 2–4 אפשרויות לשאלה, המומלצת ראשונה עם "(מומלץ)", עד 4 שאלות בקריאה אחת.
  השאלה והאפשרויות בעברית.
- **רשימת משימות גלויה** בכל עבודה מרובת שלבים: התוכנית מוצגת ומתעדכנת, צעד אחד "בתהליך" בכל רגע.
- **אחרי עריכת סוכן או skill:** `node .kit/check.mjs --fix`, ואז `node .kit/check.mjs` → 0 נכשלו. לא עורכים ידנית את
  `.codex/agents/*.toml` או את `.agents/skills/`.
- **זיכרון:** הזיכרון האישי של Claude Code אינו מקור אמת לפרויקט — החלטות נרשמות ב-`docs/decisions-log.md`.
- **מחברים (MCP):** בעל הפרויקט מתחבר בעצמו; Claude לא נכנס לחשבון ולא מקליד סיסמה או 2FA.
- **סתירה:** ב-Claude Code `CLAUDE.md` גובר על `AGENTS.md`. לכן לא כותבים כאן כלל שסותר את החוקה — משנים את `AGENTS.md`.
