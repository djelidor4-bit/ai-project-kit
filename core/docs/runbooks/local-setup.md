# הגדרה מקומית — runbook

> **המטרה:** אדם חדש, או סשן AI חדש, מרים את כל המערכת על מחשב נקי ומריץ את בדיקת הזרימה הסטנדרטית. הוא עושה את זה
> מהמסמך הזה בלבד, בחינם, ובתוך ⏳ דקות.
> **"עובד" =** הפקודה ב-§3 מסתיימת ב-0 נכשלים ו-0 "לא נבדק". דילוג אינו הצלחה, ובדיקה שלא הצליחה לרוץ נחשבת נכשלת.
> **מקומית כל הספקים החיצוניים הם Mock:** אין SMS או מייל אמיתי, אין תשלום, ואין קריאה בתשלום למודל.
> **מצב:** ⏳ למלא: "לא נבדק" / "נבדק ב-YYYY-MM-DD על מחשב נקי, ע"י …"

## 0. דרישות מוקדמות

| כלי | גרסה | בדיקה |
| :--- | :--- | :--- |
| git | ⏳ למלא | `git --version` |
| ⏳ למלא (לדוגמה: Node, Python, Docker) | ⏳ למלא | ⏳ למלא |

- **מאגרים לשכפל:** ⏳ למלא: רשימה. אם יש כמה מאגרים, כולם בתיקיית אב אחת.
- **קובץ `.env`:** מעתיקים `.env.example` ל-`.env` בכל מאגר.
  ⏳ למלא: מאיפה משיגים ערכים מקומיים שאינם ברירת מחדל. הערכים לא נמצאים בגיט ולא נשלחים בצ׳אט.
- **מערכת הפעלה:** ⏳ למלא: מה נבדק (Windows / macOS / Linux). מה שלא נבדק מסומן "לא נבדק".

## 5. תקלות נפוצות

| סימפטום | סיבה | פתרון |
| :--- | :--- | :--- |
| "הפורט תפוס" | שרת ישן עדיין רץ, או שחבילה אחרת רצה במקביל | לכבות לפי ה-PID. אם החבילות רצות במקביל, לתת לכל חבילה בלוק פורטים משלה |
| בדיקה עוברת או נכשלת מהסיבה הלא נכונה | שתי חבילות חולקות פורט, והבקשות מגיעות לשרת של השנייה | בלוק פורטים לכל חבילה, ותיעוד שלו ב-`docs/runbooks/` |
| התנהגות מקומית שונה מהייצור | `.env` חסר, או שברירת המחדל בקוד שונה מהייצור | להשוות מול `docs/environments.md` §3 |
| diff ענק בלי שינוי אמיתי, או בדיקת hash שנכשלת | סופי שורות CRLF מול LF, בדרך כלל ב-Windows או ב-worktree | `.gitattributes` שקובע את סופי השורות |
| חלון טרמינל נפתח לכל שרת (Windows) | סקריפט ההרמה לא מסתיר חלונות | להסתיר את החלונות בסקריפט (ב-Node: `windowsHide: true`) |
| תהליכים יתומים אחרי ריצה (שרתים, דפדפן headless) | הריצה נקטעה לפני הניקוי | לסיים לפי עץ התהליכים ולפי תיקיית הפרופיל הזמנית. לא לפי שם, כדי לא לסגור את הדפדפן של המשתמש |
| ⏳ למלא | | |
