# daily-summaries — סיכומי יום

> סיכום לכל יום עבודה, **החדש למעלה**. כותב: הסוכן הראשי, בסוף יום או סשן משמעותי. קצר — עובדות ומספרים, לא סיפור.
> אסור כאן: סודות, ערכי משתני סביבה, מידע אישי, טקסט שיחה של משתמשים, תוכן מסמכים.

## המבנה של יום

```
## YYYY-MM-DD
- **מה נעשה:** ... (עם קודי החלטה ומפתחות משימה)
- **בדיקות:** איזו פקודה או חבילה, ובמספרים — "N/N, 0 נכשלו". דילוג אינו הצלחה.
- **מה לא נבדק:** במפורש.
- **commit / push / deploy:** hash ואיפה — או "אין commit".
- **נשאר פתוח:** משימות ושאלות שנפתחו או נשארו.
- **תקלות ולקחים:** מה השתבש ומה משתנה בעקבותיו (רק אם היה).
```
