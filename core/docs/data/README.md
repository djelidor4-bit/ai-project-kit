# docs/data — נתונים בגיט: מה מותר, מה אסור, ואיך בודקים לפני push

> כאן נמצאים נתונים שהם **ראיה או הגדרה**: תוצאות ריצות, מילוני נתונים, סכמות ו-fixtures סינתטיים.
> זה לא המקום לנתוני משתמשים. כללי האחסון המלאים: `docs/engineering-operating-model.md` §8.1.

## מה מותר כאן

- תוצאות ריצות בדיקה והערכה (מספרים, מזהים, ציונים). תיקייה לכל ריצה: `docs/data/<נושא>-YYYY-MM-DD/`.
- `data-model.md` — מודל הנתונים ומילון הנתונים, **המיקום היחיד**: ישויות, שדות, הבעלים והרגישות של כל שדה.
- נתונים סינתטיים ו-fixtures שנבנו לבדיקות.
- סיכומים מצטברים בלי פרטים של אדם.

## מה אסור כאן, ובכל מקום בגיט

| אסור | למה |
| :--- | :--- |
| מידע אישי של משתמשים, לקוחות או אנשים שאינם בצוות: טלפון, מייל, שם, מספר זהות, כתובת, מידע רפואי או פיננסי | גיט זוכר לנצח. מחיקה דורשת שכתוב היסטוריה |
| קבצים שמשתמשים העלו | כלל אחסון (§8.1) |
| פלטים שנוצרו בזמן ריצה | כלל אחסון. חריג = שורה בטבלת החריגים (§8.1) עם תנאי יציאה |
| טקסט שיחה של משתמשים אמיתיים | פרטיות. במקומו נשמרים מזהים וספירות |
| dump של מאגר הייצור | פרטיות וסודות |
| secrets, טוקנים, מפתחות | §8.3. בגיט מותר רק שם המשתנה |
| גיבוב של סיסמה, טלפון או מספר זהות | גיבוב כזה הפיך כשהמלח ידוע |

- **שמות ותפקידים של אנשי הצוות** ב-`AGENTS.md` וביומן — מותרים.
- **נתונים שנאספו בניסוי עם אנשים** נשמרים בגיט רק עם כינוי, ולא עם שם.
- **קובץ מעל ⏳ MB** לא נכנס לגיט. הוא נשמר באחסון חיצוני, ובגיט נשאר קישור.

## הסריקה לפני push — מפתחות **וגם** מידע אישי

הסריקה רצה על מה שנכנס ל-commit (`git diff --cached`), ולא רק על הקבצים שנגעת בהם. היא מחפשת:

1. **מפתחות וסודות:** תבניות של מפתחות API, טוקנים, `PRIVATE KEY`, מחרוזות ארוכות אחרי `key=`, `secret=` או `token=`, וקבצי `.env`.
2. **מידע אישי:** מספרי טלפון, כתובות מייל, מספרי זהות, ושמות מרשימה ידועה של משתמשים או לקוחות (אם יש; לא שמות הצוות).
3. **קבצים שאסור שייכנסו:** העלאות, פלטים, dumps, וקבצים גדולים.

⏳ למלא: הפקודה שמריצה את הסריקה בפרויקט (סקריפט מקומי חינמי, או כלי סריקה שאושר ביומן).

- **ממצא = עצירה.** לא דוחפים. מוציאים את הקובץ מה-commit ומוסיפים ל-`.gitignore` אם צריך.
- **ממצא שכבר נדחף** הוא אירוע. ה-AI עוצר ומדווח; בעל הפרויקט מחליף את הסוד מיד; שכתוב היסטוריה רק בהחלטה שלו.
- הסריקה היא חלק מה-regression של כל push (`docs/engineering-operating-model.md` §9.3, סעיף א).
